01 / The starting point

The data was in Excel.
The questions crossed every file.

We took the GDS well-level export and its matching parameter export and brought them into one browser workspace.

INPUT A

Corrected well values

Compound IDs, targets, concentrations and individual responses from the QC Layer Corrected column.

Masked or ignored wells are excluded from analysis.

INPUT B

Reported parameters

The matching export supplies Activity (cmax), qAC50, fitted plateaus, R² and available validity / QC information.

Reported values stay traceable to the source.

THE QUESTIONS

What is active, and where?

Inspect each dose response, list active compounds by target, compare selectivity and see which target has the most hits.

Keep the original full RMC identifiers, including batch suffixes.

The prototype supports the specific export layouts tested so far. New GDS layouts need example files and a parser check.
02 / What we did

One workflow, from wells to interpretation.

We used the corrected values already provided in the exports, then added consistent plotting, activity calls and exploratory analysis.

01 · READ

Match the exports

Join wells and reported parameters by compound and target. Keep concentrations in µM and preserve the full RMC ID.

02 · ANALYZE

Summarize and refit

Calculate dose means and SD. Fit an independent four-parameter logistic curve to included positive-dose wells.

03 · CLASSIFY

Apply the activity rule

Call active when the reported Activity (cmax) is strictly above 120. Keep source QC flags visible.

04 · EXPLORE

Compare the profiles

Build curves, parameter tables, a heatmap, target rankings, activity overlap and a PCA response map.

Two details matter: qAC50 is converted from M to µM with its qualifier retained. With wells alone, Cmax uses the observed peak dose mean and is labeled separately.

05 / How to read the results

Useful evidence, with its context attached.

ACTIVITY

Cmax is the current hit rule

Active means Cmax > 120 in this workflow. It is separate from potency, curve quality and confidence in a result.

A flagged curve can still meet the activity rule.

POTENCY

Reported and refitted stay separate

The independent 4PL is exploratory and uses its own fitting approach. It may differ from the GDS fit.

“>10 µM” stays qualified; an extrapolated estimate needs inspection.

SIMILARITY

The map compares assay responses

PCA groups compounds by measured target profiles. Correlations summarize patterns across compounds.

These views do not establish chemical similarity or a shared mechanism.

Today’s scope is one matched experiment at a time. Well-level SD is not a biological confidence interval. Biological replicate aggregation and significance testing are future work.
06 / What we plan next Proposed roadmap

Build confidence first.
Then connect assays and history.

Next · Biological replicates

Does the result reproduce?

  • Label independent experiments separately from technical wells.
  • Compare per-experiment curves, potency and activity calls.
  • Agree how to summarize estimates, variability and inconsistent results.
Then · Multiple assays

Is there supporting evidence?

  • Add TR-FRET, crosslinking and primary-screen records.
  • Define each assay’s response units, controls and hit rules.
  • View an evidence matrix and linked curves for each compound.
Then · Screen history

What changed over time?

  • Link current and previous primary screens by stable compound IDs.
  • Track experiment date, time point, batch and assay version.
  • Compare hit agreement and follow-up outcomes across runs.
Each assay needs its own interpretation. The Cmax > 120 rule will not be automatically applied to every assay. A single-concentration primary screen cannot supply an EC50.
07 / The next views Proposed, not implemented

Turn separate experiments into an evidence map.

Add views that answer a specific decision question, with the supporting records one click away.

Replicate agreement

Per-experiment potency plots and side-by-side curves to expose reproducible effects and discordant runs.

Compound × assay evidence matrix

Separate activity, QC, repeat support and missing measurements so an untested assay is never treated as inactive.

Screen-to-follow-up comparison

Link previous and current primary-screen calls with concentration-response follow-up and orthogonal assay evidence.

Traceable summaries

A future AI-written summary could point back to source measurements and flag missing evidence. It would need separate evaluation before use in prioritization.

The current PCA and clustering are statistical views. AI summaries and predictions are future possibilities; they are not part of today’s analysis.

09 / The next step

Start with one small, complete data package.

To build the next iteration, we need representative data plus the context that makes it interpretable.

  • One complete biological-repeat set
    Matched exports and clear experiment / replicate labels.
  • One example per new assay
    TR-FRET, crosslinking and a linked previous / current screen pair where available.
  • A short assay dictionary
    Units, response direction, controls, normalization and hit rules.
  • A reviewer and a reference analysis
    Agree expected outputs and check representative curves together.

Proposed acceptance checks

Compound IDs and units match the source. Technical and biological repeats stay distinct. Reference parameters and hit lists reconcile, or differences are explained.

New views expose source records, QC and missing data. Assay owners review the interpretation before wider use.
