01 / Background · October 2026

GDS data analysis
What I have done so far

I started with two GDS Excel exports and built a browser tool, Target Atlas, to plot the corrected responses and compare compound activity across targets.

The questions I wanted to answer were:

  • What do the dose–response curves look like for each compound and target?
  • Which compounds meet our activity rule of Cmax > 120?
  • How do the response patterns compare across targets?
Current dataset: one 24-hour experiment; 28 full RMC compound/batch IDs; 2,240 corrected wells.
Targets analyzed: Cyclin D3, Cyclin E1, Cyclin K and CDK4.

This is a walkthrough of the input files, processing steps and outputs, followed by ideas and questions for the group.

02 / Files and processing

What I took from the GDS exports

Well-level export

  • Full RMC ID, target and concentration.
  • Response from the QC Layer Corrected column.
  • Individual wells and any masked / ignored status.

Matching parameter export

  • Reported Activity (cmax) and qAC50.
  • Reported curve parameters and fit information.
  • Validity and “Potential Issues” fields.

Processing steps

  1. Match the well data and reported parameters by compound and target.
  2. Keep full RMC IDs, including batch suffixes; express concentrations in µM.
  3. Use the corrected responses supplied by GDS. Exclude masked or ignored wells.
  4. Calculate the mean and SD at each dose, and retain individual wells for inspection.

I used GDS’s existing corrected values; I did not develop a new normalization method. Reported qAC50 values are converted from M to µM, with qualifiers such as “>” retained.

03 / Example output: curves

Dose–response plots for each RMC ID

Each compound has a plot for every measured target. The view shows individual wells, dose means ± SD, an independent 4PL fit and the activity cutoff.

The independent 4PL fit is an exploratory refit. It uses its own constraints and is kept separate from the GDS-reported parameters; equivalence to GDS or Prism has not been established.

How activity is assigned

The current rule is reported Activity (cmax) > 120, using the unrounded value. A QC flag stays visible and does not automatically change that call.

With a well-only upload, Cmax instead uses the highest observed dose mean and is labeled accordingly. Those two definitions can give different hit lists.

06 / Other outputs and current limits

What is available to look at now

Outputs I added

  • A compound × target heatmap with Cmax values and activity calls.
  • A summary of which target combinations are active for each ID.
  • A PCA map of measured response profiles, clustered heatmap ordering and target correlations.
  • CSV parameter tables, SVG plots and printable curve reports.

What still needs checking

  • Reference curves and fitting settings against GDS / Prism.
  • How the assay team wants QC flags handled.
  • Reproducibility across independent biological experiments.
  • Import behavior for export layouts beyond the files used so far.

PCA and correlations describe response patterns; they do not establish chemical similarity or mechanism. The current tool handles one matched experiment at a time. Well-level SD describes variation within a dose, not biological uncertainty.

The tool runs in the browser. Uploaded data is processed locally and cleared on reload; exported results can be kept. The included RMC dataset is visible at the public link.

07 / Ideas for the next analysis

What I would like to add

Biological replicates

Keep independent experiments separate from technical wells, compare curves and activity calls between runs, and agree how to summarize variability.

Other assays

Bring in TR-FRET, crosslinking and primary-screen data, starting with one example. Each assay would need its own units, controls and activity definition.

Previous screens

Link current and previous primary-screen records by compound ID so we can see how initial hits relate to follow-up results.

These are ideas for discussion and are not implemented yet. The Cmax > 120 rule should not be transferred automatically to other assays. Single-concentration screen results would be recorded as screen results, without an EC50.

08 / Discussion with the group

Where I need input from colleagues

  • For biological replicates: one matched set of well and parameter exports from independent repeats, with experiment IDs, dates and technical-well labels.
  • For checking the analysis: a few reference GDS or Prism curves and feedback on fitting settings, the Cmax rule and source QC flags.
  • For another assay: a representative TR-FRET, crosslinking or primary-screen export, plus the readout, units, controls and how activity is defined.
  • For screen history: matching current and previous screen records, with concentrations and compound / batch identifiers.

A useful starting point would be to review a few curves together and try one biological-repeat set. We can then decide which additional assay comparison would be most useful.

Questions for discussion: Do these outputs help with our analysis? Which interpretation or format needs changing? Which dataset should we try next?
